# LiveOps Enhancer

Userscript com melhorias de usabilidade para a página de pesquisa de chamados do Seidor LiveOps.

Adiciona melhor navegação da tabela, rolagem horizontal, ordenação crescente e decrescente, reorganização persistente de colunas, foco da tabela e cópia configurável em Markdown.

O objetivo é tornar a consulta e o acompanhamento diário de chamados mais práticos, sem alterar o funcionamento do sistema original.

## Instalação

1. Instale o [Tampermonkey](https://www.tampermonkey.net/).
2. [Instale o LiveOps Enhancer](https://raw.githubusercontent.com/Luiz-Filipe26/liveops-enhancer/main/liveops-enhancer.user.js).
